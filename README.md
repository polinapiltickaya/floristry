# ФЛОРИСТИКА — База знаний

Веб-приложение — база знаний по флористике. Содержит информацию о растениях, букетах, стилях флористики, магазинах Гродно и обучающих материалах.

**Автор:** Пильтицкая П.В.  
**Дисциплина:** Проектирование баз знаний, 2026

---

## Возможности

- **Поиск** по всей базе знаний 
- **Растения** — название (русское и латинское), категория, цвет, сезон, описание, уход, подходящие поводы и букеты
- **Букеты** — состав, стиль, поводы, магазины, где можно заказать
- **Стили флористики** 
- **Материалы**
- **Магазины** — цветочные салоны Гродно 

## Стек технологий

- **Backend:** Python 3, Flask
- **База данных:** SQLite
- **Frontend:** HTML, CSS
